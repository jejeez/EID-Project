# EID Project

Arduino/ESP32 code, Nextion touchscreen UI, and SolidWorks CAD files for my EID project.

## Folder guide

| Folder / file | What it is |
|---|---|
| `working_final_no_revisi/` | Final working Arduino sketch (Nextion display + servo control) |
| `test*/`, `test_coordinates/`, `testmotoresp32/`, `serialmonitortest/` | Test sketches used during development |
| `nextiondisp/` | Nextion Editor project (`ScreenUI.HMI`) and fonts |
| `eid_attempt (3).tft` | Compiled Nextion display file |
| `Shelves/`, `Linear Slider/`, `Linear Actuator/`, `rover fritz/` | SolidWorks parts and assemblies |
| `everything.SLDASM` | Full assembly |
| `*.STL` | 3D-print files |

## Requirements

- Arduino IDE
- Nextion Arduino library (ITEADLIB_Arduino_Nextion)
- Servo library
- Nextion Editor (to open the `.HMI` file)
- SolidWorks (to open the CAD files)
